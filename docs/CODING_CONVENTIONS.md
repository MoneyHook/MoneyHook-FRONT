# コード規約

- 1ファイルは画面合成、表示パネル、状態/副作用、データ変換のいずれか1つの責務を持つ。密結合な型・定数・helperは同居でき、小部品ごとの機械的分割は不要。
- 手書き実装は300行、テストは400行まで（ESLint `max-lines`、空行・コメントを除く）。OpenAPI生成物と外部由来の`shared/components/ui`は除外。
- 超過した移行対象はESLint設定でwarningにする。対象を変更するときに上限内へ分割し、移行リストから外す。
- 例外コメントで上限を回避しない。分割不能なら責務の境界と案をレビューで合意して規約を変更する。
- 親コンポーネントはURL・取得・イベントの接続と表示合成に専念する。独立して変更できるパネル・チャート・選択シート・一覧・状態管理を抽出する。
- 公開export・依存方向・共通化は[アーキテクチャ](ARCHITECTURE.md#コード構造)に従う。

変更した実装・テストのESLintだけを[検証方針](DEVELOPMENT.md#検証)に従って実行し、行数エラーを解消する。文書のみならlint不要。
