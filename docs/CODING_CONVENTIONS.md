# MoneyHooks React コード規約

## ファイルの責務とサイズ

- 1ファイルは、画面の組み立て、独立した表示パネル、状態と副作用、データ変換のいずれか1つの責務を持ちます。
- 手書きの実装ファイルは300行まで、テストファイルは400行までとします。ESLintの`max-lines`で空行とコメントを除いて検査します。
- OpenAPI生成コードと`shared/components/ui`の外部由来UIプリミティブは行数規約の対象外です。
- 独立して理解・テスト・変更できるパネル、チャート、選択シート、一覧、状態管理は別モジュールへ抽出します。
- その責務に密結合な小さな型、定数、整形関数、private helperは同居できます。Reactコンポーネントを機械的に1つずつ分けることは目的ではありません。
- 上限を例外コメントで回避しません。責務を分割できない場合は、責務の境界と分割案をレビューで合意してから規約を変更します。
- 規約導入時点で超過しているファイルは、ESLint設定の明示的な移行リストでwarningとして可視化します。該当ファイルを変更する際は、同じ変更で300行（テストは400行）以下へ分割してリストから外します。

## モジュール境界

- feature外へ公開するものは、既存どおりfeatureの`index.ts`から公開します。
- 共通化は複数の実利用がある場合にだけ行い、特定featureの業務知識を`shared`へ移しません。
- 分割後の親コンポーネントは、URL状態、データ取得、イベントの接続と表示ブロックの合成に専念します。

## 確認

変更後は`pnpm lint`を実行します。行数の超過はlintエラーとなり、解消するまで変更を完了扱いにしません。
