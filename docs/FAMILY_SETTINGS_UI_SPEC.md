# 家族設定画面 UI 仕様

仕様基準: 2026-09-30。対象は`/app/settings/family`。業務ルールは[家族仕様](FAMILY_HOUSEHOLD_DESIGN.md)、構成イメージは[concept](assets/family-settings-concept.png)（人物写真・架空メールは実装対象外）。

## 情報と順序

家計記録・集計は家族画面に置き、設定では以下の順に情報を並べる。

| 順序・領域 | 内容・操作                                                                                            |
| ---------- | ----------------------------------------------------------------------------------------------------- |
| 概要       | 家族名・状態・人数・本人の権限、表示家族の切り替え、記録へ移動                                        |
| 自分の設定 | 表示名・新規入力先の既定値（有効家族の全員）                                                          |
| メンバー   | 表示名・役割・退出状態。管理者だけが管理者交代・参加解除でき、交代前の退出不可                        |
| 招待       | 管理者だけに発行結果と履歴を表示。コード・期限・コピー・再発行・取消。最大3人、秘密は発行直後だけ表示 |
| 家族マスタ | 全員が支払方法/サブカテゴリのタブから追加・編集・有効/無効を管理                                      |
| 危険な操作 | 退出・家族終了を末尾に分離し、結果を含む確認文を表示                                                  |

未参加時は作成と招待参加を同格にする。終了済み家族は編集を隠し、閲覧専用と記録への導線を優先する。

## 表示状態

- 読み込み中は構造を保ち操作を隠す。失敗は上部で案内し、取得済み内容を消さない。
- URLの家族へアクセス不可なら理由と設定入口への戻り先を表示する。
- 有効家族だけ編集可能。「終了・閲覧専用」を明示する。
- 招待発行直後はコードを強調し、期限・コピー・共有上の注意を続ける。
- 保存中は対象操作を無効にして二重送信を防ぐ。

## 見た目と操作

- 概要・自分・メンバー・招待・マスタをカードにまとめ、面・境界線・統一余白で区別。入力欄に背景、選択入力先にアクセント。危険操作は専用カードと控えめな警告境界線。
- 短いフェード/移動で読み順を補助。入力先は選択が分かる2択、招待結果・マスタ編集は同じ場所で展開する。
- モバイルは1列、主要操作は全幅、行内操作は折り返す。デスクトップの2列は概要/日常設定とマスタのフォーム/一覧に限定する。
- メンバー名・状態を先にし、操作は右または次行。bottom navigation分の余白を確保する。
- 状態・操作名は文言を併記し、iconは補助。入力label、エラーの`role="alert"`、読み込みの`role="status"`、十分なタップ高を確保する。

受け入れ条件: 既存操作/API/権限を維持し、上記の全状態を判別できること。非管理者に管理操作を出さず、light/darkでsemantic tokenを使い、320pxからデスクトップまで横スクロールを発生させない。
